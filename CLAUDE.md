# gpuflip — контекст для Claude Code

Автономная система перепродажи видеокарт с Авито. Владелец: Данил (Москва). Цель: система, которая не уходит в минус по издержкам. Отвечать кратко, по-русски.

## Статус
Фаза 1 готова и покрыта тестами (`python -m pytest -q` → 33 passed): collector → normalizer → рынок/ликвидность → скоринг → отбор → Telegram. Покупка и продажа вручную.

## Архитектура
- `normalizer.py` — модель/память/флаги из текста; брак, ПК, ноутбуки, «куплю» отсекаются; модели с разной памятью без указанного объёма не оцениваются.
- `db.py` — SQLite; `baseline=1` у объявлений первого обхода источника (возраст неизвестен → не идут в ликвидность); `gone` ставится только после ПОЛНОГО обхода.
- `scoring.py` — net = продажа − цена·(1−торг) − издержки − заморозка − риск; scam при цене < 45% рынка; предоплата = отказ.
- `pipeline.py` — оркестрация; `cli.py` — scan/watch/report/probe/deal.

## Дорожная карта
1. (сейчас) Проверить парсер на живом Авито, накопить базу 1–2 недели.
2. Купить/продать вручную ≥20 сделок с учётом всех издержек; ROI > 0.
3. Фаза 2: шаблон первого сообщения и торг (полуавто, с подтверждением в Telegram).
4. Фаза 3: автообъявления и переоценка цены по ликвидности.
5. Фаза 4: автономная покупка — только после 50+ сделок.
6. Расширение: целые ПК (сумма комплектующих − скидка на сборку), другие комплектующие (CPU, RAM, SSD).

## Риски
Условия Авито запрещают парсинг и массовые сообщения (баны); налоги — перепродажа это ИП, не самозанятость; обман/брак — тест-стенд, без предоплаты; оборотный капитал 15–30 тыс. ₽ минимум.

## Правила
Секреты только в `.env` (в git не коммитить). Любое изменение нормализатора/скоринга — с тестом.
