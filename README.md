# gpuflip — поиск перекосов цен на Авито (видеокарты, ПК, комплектующие)

Собирает объявления, оценивает рынок по позициям и показывает лоты, которые стоят заметно дешевле: с объяснением,
расчётом **чистой** прибыли (после торга, издержек, заморозки денег и риска) и уровнем доверия.
Только поиск и уведомления: ничего не покупает, продавцам не пишет, капчу не решает.

## Установка
    pip install -r requirements.txt
    cp .env.example .env     # по желанию: TG_TOKEN, TG_CHAT_ID, режимы, пороги
    python -m pytest -q      # 141 тест должен пройти

Нужен установленный Google Chrome: сбор идёт через его окно (Playwright, отдельный профиль `.chrome-profile`).
Если Авито покажет капчу — пройдите её в этом окне сами (ждёт `CAPTCHA_WAIT` секунд, по умолчанию 180).

## Запуск
    python -m gpuflip app                         # приложение: окно, значок в трее, сбор в фоне
    python -m gpuflip app --minimized             # сразу в трей (так стартует автозапуск)
    python -m gpuflip app --no-collect            # открыть, но сбор держать на паузе

Закрытие окна сворачивает приложение в трей — сбор продолжается. Меню значка: открыть, пауза, обойти сейчас,
статус, выход. Второй запуск просто показывает уже открытое окно. Автозапуск с Windows включается галочкой в
«Настройках» (запись в `HKCU\...\Run`), там же «Проверить обновления» (`git pull` и перезапуск).
О новом кандидате приходит уведомление Windows (клик открывает объявление) и, если настроен, Telegram.

Без окна, из консоли:

    python -m gpuflip ui                          # тот же интерфейс в браузере: http://127.0.0.1:8765
    python -m gpuflip watch --interval 1200       # постоянный сбор (~20 мин с разбросом)
    python -m gpuflip scan --dry-run              # один обход, алерты в консоль
    python -m gpuflip collect --per-category 2000 # добрать каждую категорию до 2000 объявлений (часы, с паузами)
    python -m gpuflip collect --target 2000       # добрать базу до 2000 объявлений всего
    python -m gpuflip rescore                     # пересчитать базу после правки слов или порогов (сеть не нужна)
    python -m gpuflip report                      # кандидаты с режимом и объяснением, список «проверить вручную»
    python -m gpuflip report --by-mode            # по режимам: просмотрено, кандидатов, средняя прибыль, доля ушедших
    python -m gpuflip probe "<ссылка поиска>"     # проверка: достаёт ли парсер объявления с вашего IP
    python -m gpuflip deal buy <id> <цена>  |  deal sell <номер> <цена> --costs 500  |  deal stats

Один Chrome на профиль: не запускайте `scan`/`collect` одновременно с приложением — второй обход не откроется.

## Сборка exe
    build.bat                                     # → dist\gpuflip\gpuflip.exe

Собранное приложение хранит базу, `.env`, `.chrome-profile`, `sources.json` и `words\` в `%APPDATA%\gpuflip`.
База при обновлении схемы мигрирует сама; перед миграцией делается копия в `backups\`.

## Режимы поиска (флаги в `.env`, 0/1)
| Режим | Флаг | Что ищет |
|---|---|---|
| ниже рынка | всегда | модель из заголовка, цена ниже медианы позиции |
| разбор ПК | `MODE_BUNDLES` | целый ПК дешевле суммы распознанных деталей минимум на 25%; нужна видеокарта и ещё одна деталь с ценой; нераспознанное не оценивается и снижает доверие |
| регион → Москва | `MODE_REGIONAL` | лот с Авито Доставкой не из Москвы дешевле московской медианы с учётом доставки (`DELIVERY_COST`); доп. регионы — `REGIONS` |
| плохое описание | `MODE_BADTEXT` | модель найдена только в описании (доверие среднее) или после исправления опечатки (низкое, цена ≤ 60% медианы) |
| срочная продажа | `MODE_URGENT` | маркер срочности снижает порог прибыли с 15% до 10%; цена всё равно должна быть ниже медианы, штрафы за риск остаются |
| комплектующие | `MODE_CATEGORIES` | ОЗУ (тип, объём, скорость, ECC; ₽/ГБ), процессоры (точная модель), БП (мощность, сертификат, известный бренд; ₽/Вт), SSD/HDD (тип, объём) |
| проверить вручную | — | модель не определилась, а цена подозрительно низкая; в алерты не идёт |

Оценка появляется при ≥6 объявлений позиции, **алерт — только при ≥10** (`ALERT_MARKET_N`); при 6–9 — пометка «мало данных».
Ноутбучные видеокарты (3070m, Max-Q, «из ноутбука») — отдельные модели с отдельной медианой.

## Брак, риск и срочность — в текстовых файлах
Папка `words\` рядом с базой: `stop.txt` (совпадение = отсев), `risk.txt` (штраф, не отсев), `urgent.txt`
(маркеры срочности). Правятся в Блокноте; после правки — `python -m gpuflip rescore`. Отрицания («без артефактов»,
«не майнилась», «без торга») программа вырезает сама. Гарантировать исправность нельзя — это скоринг, а не проверка.

## Актуальность
За каждый обход перепроверяется несколько карточек (`RECHECK_PER_CYCLE`): кандидаты и случайные остальные.
Пропавшее объявление становится `inactive` и выходит из медианы; заодно дочитываются полное описание, состояние
(«Новое»/«Б/у») и город. Объявления, которых не видели 14 дней, в медиану тоже не идут.

## Интерфейс
- **Объявления**: фильтры (текст, категория, цена, регион, город/метро, доставка, режим, доверие, позиция, рейтинг,
  свежесть), сохранённые поиски, избранное, статус лота (новый / проверил / купил / пропустил), заметка, сортировка
  (новые, прибыль, % к рынку, цена). В карточке — ссылка на Авито, причины, значок доверия по n, график цены лота и
  медианы позиции, расчёт и штрафы риска. Пустая выдача подсказывает, какой фильтр её обнулил.
- **Рынок**: медиана, объём, новые и ушедшие по позициям, динамика за 7/30 дней.
- **Статус**: последний обход, капчи и блокировки, ошибки, сводка по режимам.
- **Настройки**: источники сбора (раздел, регион, доставка, цена, страниц), автозапуск, обновление. Тема — кнопка в шапке.

## Ограничения (честно)
- Парсинг нарушает условия Авито и ломается блокировками и сменой вёрстки. Селекторы сверены с живой страницей
  13.10.2026. Авито быстро ограничивает доступ: не уменьшайте `DELAY_SEC` и не гоняйте обходы подряд.
- В общероссийской выдаче нет города продавца — он берётся из адреса объявления; в карточке ПК описание обрезано,
  поэтому разбор ПК до перепроверки карточки видит только начало текста.
- Позиции ОЗУ, БП и дисков не различают конкретную модель — такие кандидаты идут с доверием «среднее». Материнские
  платы оцениваются только внутри разбора ПК (чипсет ≠ модель платы).
- Срок продажи не измеряется: берётся условные 14 дней. Пороги и торг — стартовые, калибруются по сделкам (`deal`).
- Налоги: регулярная перепродажа — предпринимательство; уточните у бухгалтера.
