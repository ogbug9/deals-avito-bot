# gpuflip — поиск перекосов цен на Авито (видеокарты, ПК, комплектующие)

Собирает объявления, оценивает рынок по позициям и показывает лоты, которые стоят заметно дешевле: с объяснением,
расчётом **чистой** прибыли (после торга, издержек, заморозки денег и риска) и уровнем доверия.
Только поиск, оценка и уведомления: ничего не покупает, продавцам не пишет, капчу не решает.

## Установка
    pip install -r requirements.txt
    cp .env.example .env     # по желанию: режимы, пороги (Telegram удобнее задать в «Настройках»)
    python -m pytest -q      # 190 тестов должны пройти

Нужен установленный Google Chrome: сбор идёт через его окно (Playwright, отдельный профиль `.chrome-profile`).
Если Авито покажет капчу — пройдите её в этом окне сами (ждёт `CAPTCHA_WAIT` секунд, по умолчанию 180).

## Запуск
    python -m gpuflip app                         # приложение: окно, значок в трее, сбор в фоне
    python -m gpuflip app --minimized             # сразу в трей (так стартует автозапуск)
    python -m gpuflip app --no-collect            # открыть, но сбор держать на паузе

Закрытие окна сворачивает приложение в трей — сбор продолжается. Второй запуск показывает уже открытое окно.
Автозапуск, Telegram, расписание и обновление — во вкладке «Настройки».

Без окна, из консоли:

    python -m gpuflip ui                          # тот же интерфейс в браузере: http://127.0.0.1:8765
    python -m gpuflip watch --dry-run             # постоянный сбор: редкий полный обход + лёгкий цикл
    python -m gpuflip scan --dry-run              # один полный обход, алерты в консоль
    python -m gpuflip collect --per-category 2000 # добрать каждую категорию до 2000 объявлений (часы, с паузами)
    python -m gpuflip rescore                     # пересчитать базу после правки слов или порогов (сеть не нужна)
    python -m gpuflip report                      # кандидаты с режимом и объяснением, список «проверить вручную»
    python -m gpuflip report --by-mode            # по режимам: просмотрено, кандидатов, средняя прибыль, доля ушедших
    python -m gpuflip probe "<ссылка поиска>"     # проверка: достаёт ли парсер объявления с вашего IP
    python -m gpuflip deal buy <id> <цена>  |  deal sell <номер> <цена> --costs 500  |  deal stats

Один Chrome на профиль: не запускайте `scan`/`collect` одновременно с приложением.

## Сборка exe
    build.bat                                     # → dist\gpuflip\gpuflip.exe

Собранное приложение хранит базу, `.env`, `.chrome-profile`, `sources.json` и `words\` в `%APPDATA%\gpuflip`.
Схема базы обновляется сама при старте; перед этим делается копия в `backups\`. Раз в сутки — автокопия, хранятся 7.

## Как идёт сбор
- **Полный обход** — все источники, редко (`FULL_INTERVAL_SEC`, по умолчанию раз в час). После него читаются
  карточки: лоты, прошедшие предфильтр по цене (полное описание, состояние, фото, продавец — результат кэшируется),
  и перепроверка кандидатов (жив ли лот).
- **Лёгкий цикл** — только первая страница приоритетных источников, раз в 3–5 минут (`LIGHT_MIN_SEC`…`LIGHT_MAX_SEC`).
- **Защита** — при капче, блокировке или пустом ответе интервалы умножаются на 3 (до ×16) и вдвое уменьшаются после
  каждых трёх чистых циклов. Общий потолок — `MAX_REQUESTS_PER_HOUR` загрузок страниц в час.

## Режимы поиска (флаги в `.env`, 0/1)
| Режим | Флаг | Что ищет |
|---|---|---|
| ниже рынка | всегда | модель из заголовка, цена ниже медианы позиции |
| разбор ПК | `MODE_BUNDLES` | целый ПК дешевле суммы распознанных деталей минимум на 25% |
| регион → Москва | `MODE_REGIONAL` | лот с Авито Доставкой не из Москвы дешевле московской медианы с учётом доставки |
| плохое описание | `MODE_BADTEXT` | модель только в описании (доверие среднее) или после исправления опечатки (низкое) |
| срочная продажа | `MODE_URGENT` | маркер срочности снижает порог прибыли с 15% до 10% |
| комплектующие | `MODE_CATEGORIES` | ОЗУ, процессоры, БП, диски, материнские платы |
| проверить вручную | — | модель не определилась, а цена подозрительно низкая; в алерты не идёт |

Оценка появляется при ≥6 объявлений позиции, **алерт — только при ≥10**; при 6–9 — пометка «мало данных».
Позиции: платы — сокет + чипсет + форм-фактор; ОЗУ — тип, объём, скорость, ECC; БП — мощность, сертификат; диски — тип
и объём. Если у точной позиции (с брендом) набирается 10 объявлений, оценка идёт по ней и доверие «высокое», иначе по
общей и «среднее». Продавец с тремя одинаковыми лотами или дублями объявления получает флаг «перекупщик» и штраф.
Срок продажи в расчёте — медиана срока жизни ушедших объявлений позиции; пока их меньше трёх, берутся условные 14 дней.

## Слова, аналоги — в файлах
Папка `words\` рядом с базой: `stop.txt` (совпадение = отсев), `risk.txt` (штраф), `urgent.txt` (срочность),
`analogs.json` (группы моделей близкой производительности с относительным индексом). После правки слов — `rescore`.
**Индексы в `analogs.json` — стартовая прикидка, а не замеры: проверьте и поправьте их.** Для RTX 50-й серии индексы
не заданы намеренно.

## Интерфейс
- **Сегодня** — новые кандидаты, лучший по прибыли, сколько лотов появилось и ушло, состояние сбора.
- **Объявления** — четыре вида (карточки, список, таблица, сетка; выбор запоминается), пресеты в один клик, чипы активных
  фильтров, сохранённые поиски с уведомлениями, избранное, статус, заметка, «скрыть продавца / модель», экспорт CSV.
  Таблица: сортировка по колонке, настройка колонок (показ, порядок, закрепление), профили вида. Клик по лоту открывает
  панель справа: фото, график цены и медианы, причины, расчёт, похожие лоты и разброс цен, эквиваленты дешевле,
  чек-лист проверки на месте, кнопка «Куплено».
- **Сравнение** — до 6 лотов: лучшее в строке подсвечено, худшее приглушено, «только отличия», эталонная колонка с
  разницей, сохранение набора, экспорт в CSV и картинку. Там же сравнение 2–4 моделей (выбираются на вкладке «Рынок»).
- **Рынок** — медиана, объём, новые и ушедшие, ликвидность, цена за пункт индекса, динамика за 7/30 дней.
- **Сделки** — журнал: покупка, расходы, продажа, дни, чистая прибыль, ROI, итоги за период, расчёт против факта.
- **Статус** — последний обход, капчи и блокировки, защита и лимит запросов, сводка по режимам, копии базы.
- **Настройки** — вид (плотность, шрифт, тема), Telegram с кнопкой «Тест», расписание, источники, исключения, версия
  и обновление.

Горячие клавиши (в списке): `j`/`k` — следующий/предыдущий, `Enter` — детали, `o` — Авито, `f` — избранное,
`c` — в сравнение, `x` — пропустить, `/` — поиск, `?` — шпаргалка.

## Ограничения (честно)
- Парсинг нарушает условия Авито и ломается блокировками и сменой вёрстки. Авито быстро ограничивает доступ:
  не уменьшайте паузы и лимит без нужды.
- Число объявлений продавца Авито на карточке не показывает — считается по нашей базе. Код продавца есть только у тех,
  у кого в выдаче показано имя; остальных нельзя ни скрыть, ни проверить на «перекупщика» (кроме дублей по тексту).
- Состояние «новое / б/у», все фото и полное описание есть только у лотов, чьи карточки прочитаны.
- «Ушло» определяется перепроверкой карточек, поэтому ликвидность копится медленно и долго будет «грубой».
- Гарантировать исправность нельзя — это скоринг по тексту. Налоги: регулярная перепродажа — предпринимательство.
