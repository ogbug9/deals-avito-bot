# gpuflip — фаза 1: поиск → оценка → отбор → оповещение (видеокарты)

Бот находит на Авито видеокарты ниже рынка, считает ожидаемую **чистую** прибыль (после торга, издержек,
заморозки денег и риска) и шлёт лучшие в Telegram. Покупаете и продаёте вы сами.

## Установка
    pip install -r requirements.txt   # requests, playwright, beautifulsoup4, pytest
    cp .env.example .env     # впишите TG_TOKEN, TG_CHAT_ID
    python -m pytest -q      # 56 тестов должны пройти

Нужен установленный Google Chrome: сборщик открывает его окно через Playwright (отдельный профиль `.chrome-profile`).
Если Авито покажет капчу — пройдите её в этом окне (ждёт `CAPTCHA_WAIT` секунд, по умолчанию 180).

## Команды
    python -m gpuflip ui                          # интерфейс с фильтрами: http://127.0.0.1:8765
    python -m gpuflip collect --target 2000       # первичный набор базы по всем источникам (долго, с паузами)
    python -m gpuflip scan --dry-run              # обычный обход источников, алерты в консоль
    python -m gpuflip scan                        # то же, алерты в Telegram
    python -m gpuflip scan --url "<ссылка>"       # разовый обход одной ссылки поиска
    python -m gpuflip scan --csv файл.csv         # импорт (колонки: title, price; опц. id,url,description,city)
    python -m gpuflip watch --interval 1200       # постоянный цикл (~20 мин с разбросом)
    python -m gpuflip probe "<ссылка поиска>"     # проверка: достаёт ли парсер объявления с вашего IP
    python -m gpuflip report                      # кандидаты, рынок по моделям, итоги сделок
    python -m gpuflip deal buy <id объявления> <цена>
    python -m gpuflip deal sell <номер сделки> <цена> --costs 500
    python -m gpuflip deal stats

## Источники и интерфейс
Что собирать, задаётся списком источников (`sources.json`, правится во вкладке «Настройка сбора»): раздел
(видеокарты, системные блоки, процессоры, платы, память, БП, диски, охлаждение, корпуса), регион, «только с Авито
Доставкой», цена от/до, слова в поиске, число страниц. Пока файла нет — действует набор по умолчанию из `sources.py`.

Вкладка «Объявления» — фильтры по базе: поиск по тексту, раздел, цена, регион и город/метро, доставка, рейтинг
продавца, свежесть, модель видеокарты, «только с расчётной прибылью». Брак и «куплю» по умолчанию скрыты.
Прибыль считается только для видеокарт; остальные разделы просто лежат в базе.

## Как это работает
1. **Нормализация**: модель, объём памяти, флаги риска (майнинг, не тестировалась, предоплата, ремонт).
   Брак/«на запчасти»/ПК/ноутбуки/«куплю» отсекаются. Модели с разной памятью (3060 8/12, 1060 3/6…) без указанного объёма не оцениваются.
2. **Рынок**: медиана активных цен той же модели (выбросы отрезаются, само объявление исключено).
   Нужно ≥ `MIN_MARKET_N` (6) объявлений — **первые обходы только копят базу**.
3. **Ликвидность**: объявления, пропавшие при *полном* обходе, считаются «ушедшими»; срок жизни — оценка скорости продажи
   (не учитываются те, что были при первом обходе — их возраст неизвестен). Это приблизительно: объявление могли снять, а не продать.
4. **Скоринг**: `продажа − (цена·(1−торг)) − издержки − заморозка − ожидаемые потери от риска`. Порог: ≥1500 ₽ и ≥15%.
   Цена ниже 45% рынка — подозрение на развод, не алертим. Предоплата — отказ.
5. **Оповещение**: топ по прибыли, без повторов (повтор только если цена упала ≥10%).

## Ограничения (честно)
- Парсинг Авито нарушает их условия использования и ломается блокировками/вёрсткой. Селекторы сверены с живой страницей
  13.10.2026 (фикстура в `tests/fixtures`). Авито быстро банит IP: не запускайте `probe`/`scan` подряд и не уменьшайте `DELAY_SEC`.
  Если `probe` даёт 0 объявлений — он сохраняет HTML в `probe.html`; запасной путь — `--csv`.
- Ликвидность («ушло») пока не считается: полный обход 100+ страниц невозможен.
- Пороги и `NEGOTIATION_DISCOUNT` — стартовые, подбираются по вашим сделкам (`deal`).
- Налоги: регулярная перепродажа — предпринимательство, самозанятость не подходит; уточните у бухгалтера.
- Перед фазой 2 (автопереписка): минимум 20 закрытых сделок с учётом всех издержек и положительный ROI.
